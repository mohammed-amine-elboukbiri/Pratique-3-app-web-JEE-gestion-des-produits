# 🛒 Gestion des Produits – Application Web JEE avec Spring Boot

## 📌 Présentation du projet

Ce projet consiste à développer une application Web JEE de gestion des produits en utilisant l'écosystème **Spring Boot**.

L'application permet de gérer un catalogue de produits à travers une interface Web intuitive, avec des fonctionnalités CRUD (Create, Read, Update, Delete), un système de recherche, la validation des formulaires et une gestion sécurisée des accès.

Ce projet a pour objectif de mettre en pratique les concepts étudiés dans le cadre du développement Web JEE, notamment Spring MVC, Spring Data JPA, Hibernate, Thymeleaf et Spring Security.

## 🎯 Objectifs du projet

- Développer une application Web basée sur Spring Boot.
- Manipuler les entités JPA avec Hibernate.
- Gérer les données avec Spring Data JPA.
- Créer des interfaces Web dynamiques avec Thymeleaf.
- Implémenter la validation des formulaires.
- Sécuriser l'application avec Spring Security.
- Réaliser les opérations CRUD sur les produits.

## 🛠️ Technologies utilisées

| Technologie | Description |
|---|---|
| Java | Langage de programmation |
| Spring Boot | Framework de développement |
| Spring Web | Développement Web avec Spring MVC |
| Spring Data JPA | Gestion de la couche DAO |
| Hibernate | ORM (Object-Relational Mapping) |
| Thymeleaf | Moteur de templates HTML |
| Spring Security | Authentification et sécurité |
| Spring Validation | Validation des données |
| Lombok | Réduction du code répétitif |
| H2 Database | Base de données en mémoire |
| MySQL | Base de données relationnelle |
| Bootstrap | Mise en forme de l'interface |
| Maven | Gestion des dépendances et construction du projet |
